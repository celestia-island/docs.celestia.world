# Commercial Licensing

The celestia-island ecosystem is licensed in two tiers: the **service-layer applications** use the Business Source License 1.1 (BUSL-1.1), the **generic upstream libraries** use the Synthetic Source License 1.0 (SySL-1.0), and a few repositories carry other licenses. This page explains what that means in practice and when a separate commercial license is required.

## What BUSL-1.1 means

- The source code is **visible and researchable**.
- **Production deployment is subject to the license terms** by default.
- BUSL is **not an OSI-approved open-source license**.

The BUSL parameters of this organization include an **Additional Use Grant**: the following uses are free and require **no commercial license**:

- **(a) Internal operations** — using the work for your own internal operations, without offering hosting, services, or products to external third parties.
- **(b) Non-commercial use** — academic research, teaching, personal study, evaluation, experimentation, and contribution to the upstream project.
- **(c) Public service** — government agencies and public institutions may deploy the work for public-service purposes.
- **(d) Education** — accredited educational institutions may use the work for teaching, research, campus infrastructure, and student projects.
- **(e) Modification and contribution** — you may modify the work and contribute the changes to the upstream project.

## When a commercial license is required

A commercial license is required for **hosted services, SaaS, multi-tenant platforms, or resale to external third parties** — or any production use that does not fall under the free uses listed above.

## Change Date

The **Change Date is 2030-01-01**. On and after that date, BUSL-1.1 automatically converts to **SySL-1.0** (Synthetic Source License, a contract-style license designed for AI-generated code — likewise not an OSI-approved open-source license).
