# 隱私政策

本政策說明 celestia-island 服務在內測期間收集哪些資料以及如何使用。

## 我們收集什麼

- **帳戶資料** —— 營運您的帳戶所需的電子郵件地址與帳戶中繼資料。
- **用量紀錄** —— API 與服務使用資料，用於內測期間及之後的計量與計費。
- **日誌** —— 正常營運過程中產生的請求與服務日誌。

## 我們如何使用

- **服務營運** —— 執行服務、認證與支援。
- **濫用防護** —— 偵測並回應濫用或攻擊。
- **用量計量** —— 衡量用量，用於內部計費與容量規劃。

## 保留

資料僅在實現上述目的所需期限內保留。日誌通常保留 30 天；帳戶與用量紀錄在帳戶存續期內保留，並加上適用法律要求的任何期限。

## 我們不會做什麼

- 我們**不出售**您的資料。
- 我們不收集或處理支付卡資料；任何未來的支付處理均由第三方提供商按其自身政策進行。

## 聯絡

有關本政策的疑問：請在相關的 [celestia-island](https://github.com/celestia-island) 儲存庫中提交 issue。
