# 安全の原則

産業制御は安全重視です。失敗は物理機器を動かすことがあります。その
ため安全性は最後に付け足されるのではなく、アーキテクチャに設計されて
います。

## 1. LLM は世界に直接触れない

[entelecheia](https://github.com/celestia-island/entelecheia) では、
モデルが見られるのはわずかなプリミティブツール（`exec`、
`write_to_var`）だけです。実際の作業はすべて、エージェントコードが
エージェント間の広範な MCP ツール群へディスパッチする、サンドボックス
化された実行パイプライン内で行われます。モデルが振る舞いを発明する
ことはできません。プラットフォームが公開するプリミティブを呼び出す
だけです。

## 2. 多層の安全深度

物理世界に影響を与えうるすべての操作は、完全なチェーンを順に通過
します。

1. **指示レビュー** —— モデルが何をするよう指示されたか
2. **サンドボックス実行** —— コードはポリシー制約付きで分離実行される
3. **ポリシー検証** —— 書き込みゲート: 操作はポリシーに一致するか？
4. **人間の確認** —— 取り消し不能な操作に対する最終判断
5. **監査証跡** —— すべてが記録され、沈黙するものはない

## 3. 混合クリティカリティ: リアルタイムは LLM に依存しない

システムは応答時間で分割され、**高速なレイヤは決してモデルのオンライン
状態に依存しません**:

| レイヤ | 周期 | 実行環境 | LLM 依存 |
| --- | --- | --- | --- |
| L3 — 認知 | 秒〜分 | arona、shittim-chest、entelecheia（Linux） | 主な消費者 |
| L2 — 世界モデル | 10〜50 Hz | プラットフォームサービス | 任意 |
| L1 — 反応 / エッジ | 10〜100 Hz | SBC 上の evernight。小型ローカルモデル | なし |
| L0 — リアルタイム制御 | 100 Hz〜1 kHz | MCU 高速ループ、ローカルインターロック | 決してない |

LLM がオフラインになっても、プラットフォームは優雅に劣化します。安全
状態になるか、承認済みの軌道の実行を継続するかです。ハードウェア
ウォッチドッグがこの意味論を支えます —— 制御は決してネットワーク呼び
出しを待ちません。

## 4. ゼロトラスト、フェイルクローズ

- 認証と認可は [kirino](https://github.com/celestia-island/kirino) から
  得られます。短命セッションの JWT、Argon2id パスワードハッシュ、
  ログインレート制限、RBAC エンジン。
- 登録はデフォルトで招待制。デプロイメントの最初のユーザーが管理者に
  なり、以降は自己登録がロックされます。
- 明示的に許可されていないものは拒否されます。サービスに *mock* モード
  がある場合、mock モードはデフォルトでオフになり、明示的なフラグなし
  では本番デプロイメントで動作を拒否します。

## 5. 失敗は明確に

静かな劣化は安全上のバグとして扱われます。メモリ呼び出しが失敗した、
バックエンドに到達できない、デプロイが失敗した —— その場合、API
レスポンスと UI は明示的に知らせなければなりません。偽の成功も、偽
データへのフォールバックもありません。この規則は、実インシデントが
示したこと —— 見えない失敗こそが危険な失敗である —— に基づいています。
