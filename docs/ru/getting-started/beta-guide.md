# Руководство по закрытой бете

**Внутренняя закрытая бета** охватывает весь продуктовый цикл — от регистрации
учётной записи до промышленного управления. Участие только по приглашению.

## Что охватывает бета

1. **Зарегистрируйте учётную запись и создайте API key** в облачной
   API-админке [Arona](https://github.com/celestia-island/arona). Во время
   беты панель доступна только внутри (`arona:8420` на хосте развёртывания).
2. **Разверните модель** и привяжите её к чат-бэкенду через панель.
3. **Общайтесь и запускайте агентов** из desktop-приложения
   [shittim-chest](https://github.com/celestia-island/shittim-chest);
   оркестрацию агентов обеспечивает рантайм **scepter** от entelecheia.
4. **Промышленное управление**: удалённые операции и брокеринг протоколов
   работают через [evernight](https://github.com/celestia-island/evernight).

## Как получить доступ

- Доступ **по приглашениям**. Публичная самостоятельная регистрация закрыта
  по умолчанию.
- Приглашения выдаются мейнтейнерами и привязаны к одной учётной записи.
- По вопросам доступа обращайтесь через каналы, перечисленные в разделе
  [Вклад](../meta/CONTRIBUTING.md).

## Как сообщать об ошибках

Сообщайте о проблемах на GitHub, по одной ошибке на issue, используя шаблоны
issues:

| Продукт | Репозиторий |
| --- | --- |
| Чат desktop/web — shittim-chest | [celestia-island/shittim-chest](https://github.com/celestia-island/shittim-chest/issues) |
| Оркестрация агентов — entelecheia/scepter | [celestia-island/entelecheia](https://github.com/celestia-island/entelecheia/issues) |
| Промышленное управление — evernight | [celestia-island/evernight](https://github.com/celestia-island/evernight/issues) |
| Админ-панель и платформа — arona/plana | [celestia-island/arona](https://github.com/celestia-island/arona/issues) |

Всегда указывайте: информацию об окружении (ОС, версии продуктов), шаги
воспроизведения, ожидаемое и фактическое поведение, а также релевантные
журналы.

## Известные ограничения

- Панель Arona **доступна только внутри** и во время беты не публикуется
  наружу.
- Регистрация закрыта по умолчанию; открытая регистрация пока недоступна.
- WebRTC-ретрансляция устройств и живая SCADA-телеметрия требуют работающего
  экземпляра scepter; без него UI откатывается к имитированным демо-данным.
- Мобильные приложения и плагины IDE не входят в эту бету.
- Некоторые языки документации переведены частично.
