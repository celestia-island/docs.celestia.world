# 상용 라이선스

celestia-island 생태계는 두 계층으로 라이선스가 적용됩니다. **서비스 계층 애플리케이션**에는 Business Source License 1.1(BUSL-1.1)이, **범용 업스트림 라이브러리**에는 Synthetic Source License 1.0(SySL-1.0)이 사용되며, 일부 저장소에는 다른 라이선스가 적용됩니다. 이 문서는 그것이 실무에서 어떤 의미인지, 그리고 별도의 상용 라이선스가 필요한 경우를 설명합니다.

## 라이선스 지도

| 저장소 | 라이선스 |
| --- | --- |
| arona, shittim-chest, scriptum, entelecheia, e.celestia.world, dev.celestia.world, evernight | BUSL-1.1(서비스 계층) |

| docs.celestia.world 콘텐츠 | CC0-1.0 |

## BUSL-1.1의 의미

- 소스 코드는 **열람과 연구가 가능**합니다.
- **기본적으로 프로덕션 배포는 라이선스 조항의 적용을 받습니다**.
- BUSL은 **OSI가 승인한 오픈소스 라이선스가 아닙니다**.

이 조직의 BUSL 파라미터에는 **추가 사용 허가(Additional Use Grant)**가 포함되어 있습니다. 다음 용도는 무료이며 **상용 라이선스가 필요하지 않습니다**.

- **(a) 내부 운영** — 외부 제3자에게 호스팅, 서비스 또는 제품을 제공하지 않고 자체 내부 운영을 위해 저작물을 사용하는 경우.
- **(b) 비상업적 사용** — 학술 연구, 교육, 개인 학습, 평가, 실험, 그리고 업스트림 프로젝트에의 기여.
- **(c) 공공 서비스** — 정부 기관과 공공기관은 공공서비스 목적으로 저작물을 배포할 수 있습니다.
- **(d) 교육** — 인증된 교육기관은 교육, 연구, 캠퍼스 인프라 및 학생 프로젝트에 저작물을 사용할 수 있습니다.
- **(e) 수정과 기여** — 저작물을 수정하고 그 변경 사항을 업스트림 프로젝트에 기여할 수 있습니다.

## 상용 라이선스가 필요한 경우

**외부 제3자를 위한 호스팅 서비스, SaaS, 멀티테넌트 플랫폼 또는 재판매**, 또는 위에 나열된 무료 용도에 해당하지 않는 모든 프로덕션 사용에는 상용 라이선스가 필요합니다.
