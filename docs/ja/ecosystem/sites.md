# サイトと所有

このエコシステムのドキュメントは 1 つの規則に従います。**ハブはなぜ・
どこにあるかを説明し、各プロジェクトサイトはどうやるかを説明します。**
これにより、ハブは小さく、プロジェクトサイトは権威あるものに保たれ
ます。

## 誰が何を所有するか

| サイト | 所有 | コンテンツ |
| --- | --- | --- |
| [docs.celestia.world](https://docs.celestia.world) | エコシステム | 哲学、エコシステムマップ、始め方、ガバナンス（ライセンス、CLA、CoC、セキュリティ、コントリビュート） |
| `<name>.docs.celestia.world` | 各プロジェクト | ガイド、アーキテクチャ、設計、リファレンス —— 各プロジェクトのリポジトリから構築 |
| [celestia-island.github.io](https://celestia-island.github.io) | 組織 | プレゼンス、リンク、ブランドアセット |
| [e.celestia.world](https://e.celestia.world) | 公開の顔 | ランディングページ、価格、ブログ、コールトゥアクション |
| [dev.celestia.world](https://dev.celestia.world) | 開発者 | 開発者ポータルとステータス |

## 唯一の規則: 重複しない

- ハブはプロジェクトドキュメントを**決してコピーしません**。トピックが
  プロジェクトに属する場合（プロトコルの仕組み、サービスの設定方法な
  ど）、ハブは要約する代わりにプロジェクトサイトへリンクします。
- プロジェクトサイトは、哲学やクロスプロジェクトの文脈についてハブへ
  リンクを**貼ることができます**。
- プロジェクトが独自ドキュメントを維持するに足る規模になったとき、
  ハブはそのカバレッジをマップの項目とリンクに縮小します。

## サイトの構築方法

すべてのドキュメントサイト（本サイトを含む）は、プロジェクトのリポジ
トリにある Markdown から [lagrange](https://github.com/celestia-island/lagrange)
で構築され、共通の言語切り替えを持ちます。コンテンツは英語で執筆され、
翻訳は同じ構造に従い、部分的である場合はその旨が示されます。
