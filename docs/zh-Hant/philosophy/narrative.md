# 敘事與地平線

## 延遲即命運

訊號往返：月球 **2.6 秒**，火星 **6 到 44 分鐘**。離地球這麼遠的機器不能等人類下指令。它們必須**本機、安全、可預期**地決策——既有行動的權威，也有拒絕的紀律。

這就是整個生態為之構建的地平線。我們今天為工業控制所做的一切選擇，都為了讓它與未來月球或火星機器人所需的是**同一形態**：

- **智能體決策層** —— 規劃與編排
- **世界模型** —— 知道此刻正在發生什麼
- **安全門** —— 能說不，背後是永不依賴網路的即時控制

月球不是行銷故事：它是分層存在的原因。

## 路線

生態以門檻推進——上一階段出口標準達成，下一階段才解鎖：

| 階段 | 目標 | 出口標準 |
| --- | --- | --- |
| **封閉測試** | 現在 | 安全 0 P0；全閉環整合測試通過；新使用者 30 分鐘走通 註冊→金鑰→聊天 |
| **公測** | 2026 | 註冊開放；公開文件、下載與法律頁面；獨立安全審查 |
| **Y1 — 工控產線** | 2027-08 | 真實 PLC + MCU 產線展示：100 Hz 感測、10 Hz 閉環、部署包、驗收測試 |
| **Y3 — 具身設施** | 2029-08 | 可複製的具身設施包（世界狀態 + 策略層 + 參考現場），鎖定**工業具身**形態 |
| **Y5 — 航天** | 2031-08 | 全套軟硬體方案 + **至少一次在軌/飛行實證**——無 heritage 不銷售 |
| **Y5+ — 月火** | 2031+ | 自主性敘事、研究合作、白皮書 |

## 四條線共享同一資產底座

1. **B 線 — 工控**（[evernight](https://github.com/celestia-island/evernight) 主戰場）：感測管線、錄製/回放、快環、嵌入式節點。
2. **E 線 — 具身智能**：世界狀態服務、本機小模型策略層、數位孿生視覺化。
3. **K 線 — kei 即時核心**：帶 Linux ABI 人格層的確定性核心——有界可預期執行的長期解答。
4. **S 線 — 航天**：系統級三模冗餘、flight heritage、認證軌道。

一條紀律貫穿所有線：**wire 協定、世界狀態、安全門、錄製管線是共享資產。** 任何一線另起爐灶必須通過架構審查。且產品線永不依賴 kei：kei 延遲不會拖垮營收線。
