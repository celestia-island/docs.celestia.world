# クイックスタート

[クローズドループ](../philosophy/closed-loop.md) を約 30 分で歩きます。
正確なアドレスはデプロイメントによって異なります。パネル URL と招待状
は管理者に確認してください。

## 1. アカウントを取得する

登録は招待制です。デプロイメントの最初のユーザーが管理者になり、その
後は自己登録がロックされます。メンテナーに招待状を依頼してから、
Arona パネルで登録します（公開デプロイメントでは
`https://arona.celestia.world`、内部では `http://<host>:8420`）。

## 2. API キーを作成する

Arona パネルで自分のアカウントの API キーを作成します。このキーは
以下すべての身分となります —— モデル管理、チャットバックエンド、
エージェント操作。

## 3. モデルをデプロイする

パネルからモデルランタイムを選び（例: Ollama バックエンドのモデル）、
ノードにデプロイし、チャットバックエンドにバインドします。パネルには
ヘルスと利用状況が表示されます。計測と価格設定はプラットフォームレイヤ
が処理します。

## 4. チャットとエージェント実行

[shittim-chest](https://shittim-chest.docs.celestia.world)（デスクトップ
アプリまたは WebUI）を開き、API キーで接続して会話を始めます。マルチ
エージェント作業では、entelecheia の scepter ランタイムが同じインタ
ーフェースの背後でエージェントをオーケストレーションします。エージェ
ントログとツール呼び出しは UI に表示されます。

## 5. 産業機器の制御

[evernight](https://evernight.docs.celestia.world) を起動し、プロトコル
ブリッジ（Modbus、S7comm、OPC UA）を接続し、テレメトリを購読して、
ポリシー検証と人間の確認の後に書き込みを実行します。内部ベータの間、
この区間はシミュレートされた機器またはラボ機器に対して実行されます。
安全チェーンはどちらの場合も同じです。

## 6. 検証

監視ステータス（malkuth が管理するサービス）を確認し、利用記録を調べ、
問題があれば [ベータガイド](./beta-guide.md) のチャネルで報告します。
何かが壊れていれば、ループは完成していません —— どこかを教えてください。

## 失敗したら？

- **サービスがダウンしている** —— malkuth が再起動しているはずです。
  サービスのステータスページまたはログを確認してください。
- **パネルが開かない** —— 正しいホスト/ポートにいることと、デプロイ
  ヤーが組み込み WebUI を有効にしていることを確認してください。
- **メモリまたは呼び出しが利用できない** —— API レスポンスと UI が
  明示します（`memory: "offline"`）。チャットはそれがなくても動作します。
