# 封閉測試指南

**內部封閉測試**涵蓋完整的產品閉環，從帳戶註冊到工業控制。參與僅限受邀。

## 封測涵蓋什麼

1. **在 Arona 雲 API 管理面板註冊帳戶並建立 API 金鑰**。封測期間面板保持內部。
2. **部署模型**，並透過面板綁定聊天後端。
3. **在 shittim-chest 桌面應用程式聊天與執行智能體**；智能體編排由背後的智能體平台提供。
4. **工業控制**：遠端操作與協定代理經由 evernight 執行。

## 取得存取權

- 存取是**邀請制**。公開自助註冊預設關閉。
- 邀請由維護者簽發，綁定單一帳戶。
- 存取相關問題，請透過[貢獻指南](../meta/CONTRIBUTING.md)中列出的管道聯絡。

## 回報缺陷

在 GitHub 回報問題，一 bug 一 issue，使用 issue 範本。每個產品的缺陷追蹤器就是該產品的倉庫；若你沒有該倉庫的存取權，改為透過[貢獻指南](../meta/CONTRIBUTING.md)中的管道送出報告。

務必包含：環境資訊（作業系統、產品版本）、重現步驟、預期與實際行為，以及相關日誌。

## 已知限制

- Arona 面板**僅限內部**，封測期間不對外公開。
- 註冊預設關閉；開放註冊尚未提供。
- 即時設備遙測需要執行中的智能體平台；缺失時 UI 回退到模擬展示資料。
- 行動應用程式與 IDE 外掛不在本次封測範圍。
- 部分語言的文件為部分翻譯。
