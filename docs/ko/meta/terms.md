# 서비스 약관

본 약관은 celestia-island **클로즈드 베타** 서비스(arona 관리 패널, shittim-chest, 그리고 `*.celestia.world` 아래의 관련 서비스)의 이용에 적용됩니다.

## 서비스 설명

- 서비스는 **내부 베타** 단계이며 접근은 **초청제**입니다. 공개 자가 등록은 기본적으로 닫혀 있고, 초청장은 유지보수자가 발급합니다.
- 서비스는 폐쇄 루프를 다룹니다. 등록과 인증, 모델 배포, 채팅과 에이전트 실행, 산업 제어, 검증과 지원.

## 허용되는 이용

서비스를 불법적인 목적이나 적용 법령 위반에 사용하지 않고, 서비스를 악용하지 않으며(스팸, 자격 증명 공유, 무단 스크래핑, 승인된 테스트 범위를 넘는 인프라 교란 시도), 처리할 권리가 없는 데이터(무단으로 수집한 제3자의 개인 데이터나 산업 데이터 등)를 처리하지 않는 데 동의합니다.

## 가용성과 책임

본 서비스는 **SLA가 없는 베타 소프트웨어**입니다. 가용성, 데이터 내구성, 기능 안정성은 보장되지 않습니다. 서비스는 어떠한 보증도 없이 **"있는 그대로"** 제공되며, 유지보수자는 서비스 사용으로 발생하는 손해에 대해 책임지지 않습니다. 여기에는 서비스의 일부를 제한, 일시 중단 또는 중단하는 경우가 포함됩니다.

## 지식재산과 라이선스

celestia-island 프로젝트의 소스 코드는 저장소별 라이선스에 따라 공개됩니다. 별도의 명시가 없는 한 업스트림 라이브러리는 SySL-1.0, 서비스 계층 제품은 BUSL-1.1을 따릅니다. 전체 지도는 [상용 라이선스](./commercial-licensing.md)를 참조하세요. 각 저장소의 `LICENSE` 파일이 해당 코드를 규율합니다.

## 변경

본 약관은 베타 기간 동안 언제든 업데이트될 수 있으며, 중요한 변경은 관련 저장소에서 공지됩니다. 변경 후 계속 사용하면 동의한 것으로 간주됩니다.
