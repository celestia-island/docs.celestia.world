# 利用規約

本規約は、celestia-island の**クローズドベータ**サービス（arona 管理パネル、shittim-chest、および `*.celestia.world` 配下の関連サービス）の利用に適用されます。

## サービスの説明

- サービスは**内部ベータ**段階にあり、アクセスは**招待制**です。公開による自己登録は既定で無効で、招待はメンテナーが発行します。
- サービスはクローズドループをカバーします。登録と認証、モデルのデプロイ、チャットとエージェントの実行、産業制御、検証とサポート。

## 許容される利用

違法な目的や適用法令に違反する目的でサービスを使用しないこと、サービスを濫用しないこと（スパム、認証情報の共有、無許可のスクレイピング、許可されたテストの範囲を超えたインフラ妨害の試み）、処理する権利のないデータ（許可のない第三者の個人データや産業データなど）を処理しないことに同意します。

## 可用性と責任

本サービスは **SLA のないベータソフトウェア**です。可用性、データの耐久性、機能の安定性は保証されません。サービスは**「現状有姿」**で、いかなる種類の保証もなく提供されます。メンテナーは、サービスの利用から生じる損害について責任を負いません。これには、サービスの一部の制限、停止、終了が含まれます。

本規約はベータ期間中いつでも更新される可能性があります。重要な変更は関連リポジトリで告知されます。変更後の継続利用は同意を意味します。
