# 商业许可

celestia-island 生态采用两层许可：**服务层应用**使用商业源代码许可证 1.1（BUSL-1.1）；**通用上游库**使用 Apache License 2.0；个别仓库采用其他许可。本页说明其中的实际含义，以及何时需要单独的商业许可。

## BUSL-1.1 是什么

- 源码**可见、可研究**。
- **生产部署默认受许可条款约束**。
- BUSL **不是 OSI 批准的开源许可**。

本组织的 BUSL 参数带有 **Additional Use Grant**：以下情形免费，**无需商业许可**：

- **(a) 组织内部运营** —— 用于自身内部运营，不对外部第三方提供托管、服务或产品。
- **(b) 非商业用途** —— 学术研究、教学、个人学习、评估、实验，以及向上游项目贡献。
- **(c) 公共服务** —— 政府机构与公共事业单位可为公共服务目的部署本作品。
- **(d) 教育用途** —— 认证教育机构可将本作品用于教学、研究、校园基础设施与学生项目。
- **(e) 修改与贡献** —— 修改本作品并将改动贡献给上游项目。

## 需要商业许可的情形

对外部第三方提供**托管服务、SaaS、多租户平台或转售**，或任何不属于上述免费情形的生产使用，都需要商业许可。
