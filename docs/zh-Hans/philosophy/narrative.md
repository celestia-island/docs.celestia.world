# 叙事与地平线

## 延迟即命运

信号往返：月球 **2.6 秒**，火星 **6 到 44 分钟**。离地球这么远的机器不能等人类下指令。它们必须**本地、安全、可预期**地决策——既有行动的权威，也有拒绝的纪律。

这就是整个生态为之构建的地平线。我们今天为工业控制所做的一切选择，都为了让它与未来月球或火星机器人所需的是**同一形态**：

- **智能体决策层** —— 规划与编排
- **世界模型** —— 知道此刻正在发生什么
- **安全门** —— 能说不，背后是永不依赖网络的实时控制

月球不是营销故事：它是分层存在的原因。

## 路线

生态以门禁推进——上一阶段出口标准达成，下一阶段才解锁：

| 阶段 | 目标 | 出口标准 |
| --- | --- | --- |
| **内测** | 现在 | 安全 0 P0；全闭环集成测试通过；新用户 30 分钟走通 注册→密钥→聊天 |
| **公测** | 2026 | 注册开放；公开文档、下载与法律页面；独立安全审查 |
| **Y1 — 工控产线** | 2027-08 | 真实 PLC + MCU 产线演示：100 Hz 感知、10 Hz 闭环、部署包、验收测试 |
| **Y3 — 具身设施** | 2029-08 | 可复制的具身设施包（世界状态 + 策略层 + 参考现场），锁定**工业具身**形态 |
| **Y5 — 航天** | 2031-08 | 全套软硬件方案 + **至少一次在轨/飞行实证**——无 heritage 不销售 |
| **Y5+ — 月火** | 2031+ | 自主性叙事、研究合作、白皮书 |

## 四条线共享同一资产底座

1. **B 线 — 工控**（[evernight](https://github.com/celestia-island/evernight) 主战场）：传感管线、录制/回放、快环、嵌入式节点。
2. **E 线 — 具身智能**：世界状态服务、本地小模型策略层、数字孪生可视化。
3. **K 线 — kei 实时核心**：带 Linux ABI 人格层的确定性内核——有界可预期执行的长期答案。
4. **S 线 — 航天**：系统级三模冗余、flight heritage、认证轨道。

一条纪律贯穿所有线：**wire 协议、世界状态、安全门、录制管线是共享资产。** 任何一线另起炉灶必须过架构评审。且产品线永不依赖 kei：kei 延期不击穿营收线。
