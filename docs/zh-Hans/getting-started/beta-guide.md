# 内测指南

**内部封闭内测**覆盖从账户注册到工业控制的完整产品闭环。参与仅限受邀。

## 内测覆盖什么

1. **注册账户并创建 API 密钥**于 Arona 云 API 管理面板。内测期间该面板保持内部使用。
2. **部署模型**并通过面板把它绑定到聊天后端。
3. **聊天与运行智能体**于 shittim-chest 桌面应用；智能体编排由背后的智能体平台提供。
4. **工业控制**：远程操作与协议桥接通过 evernight 运行。

## 获取访问

- 访问是**邀请制**。公开自助注册默认关闭。
- 邀请由维护者签发，绑定单一账户。
- 访问问题请通过[贡献指南](../meta/CONTRIBUTING.md)中列出的渠道联系。

## 上报缺陷

在 GitHub 上报问题，一 bug 一 issue，并使用 issue 模板。每个产品的缺陷追踪器就是该产品的仓库；如果你没有某个仓库的访问权限，请改经[贡献指南](../meta/CONTRIBUTING.md)中的渠道提交报告。

务必包含：环境信息（操作系统、产品版本）、复现步骤、期望与实际行为，以及相关日志。

## 已知限制

- Arona 面板**仅限内部**，内测期间不对外公开。
- 注册默认关闭；开放注册尚未可用。
- 实时设备遥测需要运行中的智能体平台；缺失时 UI 回退到模拟的演示数据。
- 移动应用与 IDE 插件不在本次内测范围内。
- 部分语言的文档是部分翻译。
