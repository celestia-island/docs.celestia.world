# 사이트 및 소유권

이 생태계의 문서화는 하나의 규칙을 따릅니다: **허브는 왜와 어디를 설명하고,
각 프로젝트 사이트는 어떻게를 설명합니다.** 이렇게 하여 허브는 작게 유지되고
프로젝트 사이트는 권위를 갖습니다.

## 누가 무엇을 소유하는가

| 사이트 | 소유 | 콘텐츠 |
| --- | --- | --- |
| [docs.celestia.world](https://docs.celestia.world) | 생태계 | 철학, 생태계 지도, 시작하기, 거버넌스 (라이선스, CLA, 행동 강령, 보안, 기여) |
| `<name>.docs.celestia.world` | 각 프로젝트 | 가이드, 아키텍처, 설계, 참조 — 프로젝트 자체 저장소에서 빌드 |
| [celestia-island.github.io](https://celestia-island.github.io) | 조직 | 프레즌스, 링크, 브랜드 자산 |
| [e.celestia.world](https://e.celestia.world) | 대외적인 얼굴 | 랜딩 페이지, 가격, 블로그, 콜 투 액션 |
| [dev.celestia.world](https://dev.celestia.world) | 개발자 | 개발자 포털 및 상태 |

## 하나의 규칙: 중복 없음

- 허브는 프로젝트 문서를 **절대 복사하지 않습니다.** 주제가 프로젝트에
  속하는 경우(프로토콜의 동작 방식, 서비스 설정 방법), 허브는 요약하는
  대신 프로젝트 사이트에 연결합니다.
- 프로젝트 사이트는 철학과 프로젝트 간 맥락을 위해 허브로 **연결할 수
  있습니다.**
- 프로젝트가 자체 문서를 유지할 만큼 충분히 큰 경우, 허브의 범위는 지도
  항목과 링크로 축소됩니다.

## 사이트가 빌드되는 방식

모든 문서 사이트(이 사이트 포함)는 프로젝트 저장소의 마크다운에서
[lagrange](https://github.com/celestia-island/lagrange)로 빌드되며, 공유
언어 전환기를 사용합니다. 콘텐츠는 영어로 작성되며, 번역은 동일한 구조를
따르고 부분 번역일 때 표시됩니다.
