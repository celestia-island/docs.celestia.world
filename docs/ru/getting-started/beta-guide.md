# Руководство по закрытой бете

**Внутренняя закрытая бета** охватывает весь продукт-цикл, от регистрации
учётной записи до промышленного управления. Участие только по приглашению.

## Что охватывает бета

1. **Зарегистрировать учётную запись и создать API key** в облачной
   админ-панели API Arona. Панель остаётся внутренней на время беты.
2. **Развернуть модель** и привязать её к чат-бэкенду через панель.
3. **Общаться в чате и запускать агентов** из desktop-приложения
   shittim-chest; оркестрацию агентов обеспечивает агентная платформа за ним.
4. **Промышленное управление**: удалённые операции и проксирование протоколов
   идут через evernight.

## Как получить доступ

- Доступ **по приглашениям**. Публичная самостоятельная регистрация по
  умолчанию закрыта.
- Приглашения выдаются мейнтейнерами и привязаны к одной учётной записи.
- По вопросам доступа обращайтесь через каналы, перечисленные в разделе
  [Вклад](../meta/CONTRIBUTING.md).

## Как сообщать об ошибках

Сообщайте о проблемах на GitHub, одна задача на одну ошибку, используя шаблоны
задач. Трекер ошибок для каждого продукта — это репозиторий продукта; если у
вас нет доступа к репозиторию, отправьте отчёт через каналы из раздела
[Вклад](../meta/CONTRIBUTING.md).

Всегда указывайте: информацию об окружении (ОС, версии продуктов), шаги
воспроизведения, ожидаемое и фактическое поведение, а также значимые журналы.

## Известные ограничения

- Панель Arona **только внутренняя** и во время беты публично не открыта.
- Регистрация по умолчанию закрыта; открытая регистрация пока недоступна.
- Живая телеметрия устройства требует работающей агентной платформы; без неё
  UI откатывается к подставным демо-данным.
- Мобильные приложения и плагины для IDE не входят в эту бету.
- Некоторые языки документации переведены частично.
