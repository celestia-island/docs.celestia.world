# 클로즈드 베타 가이드

**내부 클로즈드 베타**는 계정 등록부터 산업 제어까지 제품 루프 전체를
다룹니다. 참여는 초대 전용입니다.

## 베타의 범위

1. Arona 클라우드 API 관리 패널에서 **계정을 등록하고 API key를
   생성**합니다. 패널은 베타 기간 내부용으로 유지됩니다.
2. 패널을 통해 **모델을 배포**하고 채팅 백엔드에 바인딩합니다.
3. shittim-chest 데스크톱 앱에서 **채팅하고 에이전트를 실행**합니다; 에이전트
   오케스트레이션은 그 뒤에 있는 에이전트 플랫폼이 제공합니다.
4. **산업 제어**: 원격 운영과 프로토콜 브로커링은 evernight를 통해
   실행됩니다.

## 접근권한 얻기

- 접근은 **초대 기반**입니다. 공개 자체 등록은 기본적으로 닫혀 있습니다.
- 초대장은 유지관리자가 발급하며 단일 계정에 바인딩됩니다.
- 접근 관련 문의는 [기여하기](../meta/CONTRIBUTING.md)에 나열된 채널로
  해주세요.

## 버그 보고

GitHub에서 버그 하나당 이슈 하나로, 이슈 템플릿을 사용해 보고해 주세요.
각 제품의 버그 트래커는 그 제품의 저장소입니다; 저장소에 접근 권한이 없다면
대신 [기여하기](../meta/CONTRIBUTING.md)의 채널로 보고해 주세요.

항상 포함해 주세요: 환경 정보(OS, 제품 버전), 재현 단계, 기대한 동작과 실제
동작, 관련 로그.

## 알려진 제한

- Arona 패널은 **내부 전용**이며 베타 기간 공개적으로 노출되지 않습니다.
- 등록은 기본적으로 닫혀 있습니다; 공개 등록은 아직 제공되지 않습니다.
- 실시간 장치 텔레메트리에는 실행 중인 에이전트 플랫폼이 필요합니다;
  없으면 UI는 시뮬레이션된 데모 데이터로 대체됩니다.
- 모바일 앱과 IDE 플러그인은 이 베타에 포함되지 않습니다.
- 일부 문서 언어는 부분 번역 상태입니다.
