# 隐私政策

本政策描述 celestia-island 服务在内测期间收集哪些数据以及如何使用。

## 我们收集什么

- **账户数据** — 运营您的账户所需的电子邮件地址与账户元数据。
- **用量记录** — API 与服务使用数据，用于内测期间及之后的计量与计费。
- **日志** — 正常运营过程中产生的请求与服务日志。

## 我们如何使用

- **服务运营** — 运行服务、认证与支持。
- **滥用防护** — 检测并响应滥用或攻击。
- **用量计量** — 衡量用量，用于内部计费与容量规划。

## 保留

数据仅在实现上述目的所需期限内保留。日志通常保留 30 天；账户与用量记录在账户存续期内保留，并加上适用法律要求的任何期限。

## 我们不会做什么

- 我们**不出售**您的数据。
- 我们不收集或处理支付卡数据；任何未来的支付处理均由第三方提供商按其自身政策进行。

## 联系

有关本政策的疑问：请在相关[celestia-island](https://github.com/celestia-island) 仓库中提交 issue。
