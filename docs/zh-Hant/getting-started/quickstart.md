# 快速開始

約 30 分鐘走完[閉環](../philosophy/closed-loop.md)。具體網址取決於你的部署；控制台位址與邀請請諮詢管理員。

## 1. 取得帳戶

註冊是邀請制：部署首個使用者自動成為管理員，此後自助註冊上鎖。向維護者索取邀請，然後在 Arona 控制台註冊（公網部署 `https://arona.celestia.world`，內網 `http://<主機>:8420`）。

## 2. 建立 API 金鑰

在 Arona 控制台為帳戶建立 API 金鑰。這個金鑰是你接下來一切操作的通行證——模型管理、聊天後端與智能體操作。

## 3. 部署模型

在控制台中選擇模型執行環境（例如 Ollama 後端模型），部署到節點，綁定聊天後端。控制台展示健康與用量；計量與定價由平台層處理。

## 4. 聊天與智能體

開啟 [shittim-chest](https://shittim-chest.docs.celestia.world)（桌面應用程式或 WebUI），用 API 金鑰連接並開始對話。多智能體場景下，entelecheia 的 scepter 執行環境在相同介面背後編排智能體；智能體日誌與工具呼叫在 UI 中可見。

## 5. 控制工業設備

[evernight](https://evernight.docs.celestia.world) 執行後，接入協定橋（Modbus、S7comm、OPC UA），訂閱遙測，並在策略校驗與人工確認後發起寫入操作。封閉測試期間此環節執行於模擬或實驗室設備；安全鏈在兩種情況下完全相同。

## 6. 驗證

查看監督狀態（malkuth 管理的服務）、檢查用量紀錄，並按[封閉測試指南](./beta-guide.md)的管道回報問題。若有斷裂，說明閉環尚未完成——告訴我們斷在哪裡。

## 出了故障怎麼辦？

- **服務掛了** —— malkuth 應已重啟它；查看服務狀態頁或日誌。
- **控制台打不開** —— 確認主機/連接埠正確，且部署時啟用了內嵌 webUI。
- **記憶或召回不可用** —— API 回應與 UI 會顯式標註（`memory: "offline"`）；聊天仍可運作。
