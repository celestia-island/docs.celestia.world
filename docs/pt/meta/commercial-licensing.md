# Licenciamento comercial

O ecossistema celestia-island é licenciado em dois níveis: os **aplicativos da camada de serviço** usam a Business Source License 1.1 (BUSL-1.1), as **bibliotecas upstream genéricas** usam a Synthetic Source License 1.0 (SySL-1.0), e alguns repositórios trazem outras licenças. Esta página explica o que isso significa na prática e quando é necessária uma licença comercial separada.

## O que significa a BUSL-1.1

- O código-fonte é **visível e pesquisável**.
- **A implantação em produção está sujeita aos termos da licença** por padrão.
- A BUSL **não é uma licença de código aberto aprovada pela OSI**.

Os parâmetros BUSL desta organização incluem uma **concessão de uso adicional (Additional Use Grant)**: os usos a seguir são gratuitos e **não exigem licença comercial**:

- **(a) Operações internas** — usar a obra para as próprias operações internas, sem oferecer hospedagem, serviços ou produtos a terceiros externos.
- **(b) Uso não comercial** — pesquisa acadêmica, ensino, estudo pessoal, avaliação, experimentação e contribuição ao projeto upstream.
- **(c) Serviço público** — órgãos governamentais e instituições públicas podem implantar a obra para fins de serviço público.
- **(d) Educação** — instituições de ensino credenciadas podem usar a obra para ensino, pesquisa, infraestrutura de campus e projetos estudantis.
- **(e) Modificação e contribuição** — você pode modificar a obra e contribuir com as alterações ao projeto upstream.

## Quando é necessária uma licença comercial

É necessária uma licença comercial para **serviços hospedados, SaaS, plataformas multilocatário ou revenda a terceiros externos** — ou qualquer uso em produção que não se enquadre nos usos gratuitos listados acima.

## Data de mudança

A **data de mudança é 2030-01-01**. A partir dessa data, a BUSL-1.1 converte-se automaticamente em **SySL-1.0** (Synthetic Source License, uma licença de estilo contratual projetada para código gerado por IA — também não aprovada pela OSI como licença de código aberto).
