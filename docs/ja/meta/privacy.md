# プライバシーポリシー

本ポリシーは、クローズドベータ期間中に celestia-island のサービスが収集するデータとその利用方法について説明します。

## 収集するもの

- **アカウントデータ** —— アカウントの運用に必要なメールアドレスとアカウントのメタデータ。
- **利用記録** —— API とサービスの利用データ。ベータ期間中およびその後の計測と課金に使用します。
- **ログ** —— 通常の運用で生成されるリクエストおよびサービスのログ。

## 利用方法

- **サービスの運用** —— サービスの実行、認証、サポート。
- **不正利用の防止** —— 不正利用や攻撃の検知と対応。
- **利用量の計測** —— 内部の課金とキャパシティ計画のための利用量の測定。

## 保持

データは上記の目的に必要な期間のみ保持されます。ログは通常 30 日間保持されます。アカウントおよび利用記録は、アカウントの存続期間と適用法令で要求される期間にわたって保持されます。

## やらないこと

- お客様のデータを**販売しません**。
- 決済カードデータは収集・処理しません。将来の決済処理は、各事業者自身のポリシーに基づき第三者事業者が担当します。
