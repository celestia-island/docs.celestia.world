# Сайты и владельцы

Документация в этой экосистеме следует одному правилу: **хаб объясняет почему
и где; сайт каждого проекта объясняет как.** Это сохраняет хаб небольшим, а
сайты проектов — авторитетными.

## Кто чем владеет

| Сайт | Владеет | Контент |
| --- | --- | --- |
| [docs.celestia.world](https://docs.celestia.world) | экосистемой | Философия, карта экосистемы, начало работы, управление (лицензия, CLA, CoC, безопасность, вклад) |
| `<name>.docs.celestia.world` | каждым проектом | Руководства, архитектура, проекты, справочники — собирается из собственного репозитория проекта |
| [celestia-island.github.io](https://celestia-island.github.io) | организацией | Присутствие, ссылки, брендовые материалы |
| [e.celestia.world](https://e.celestia.world) | публичным лицом | Лендинг, цены, блог, призыв к действию |
| [dev.celestia.world](https://dev.celestia.world) | разработчиками | Портал разработчика и статус |

## Единственное правило: без дублирования

- Хаб **никогда не копирует** документацию проектов. Если тема принадлежит
  проекту (как работает протокол, как настроить сервис), хаб ссылается на
  сайт проекта, а не пересказывает её.
- Сайты проектов **могут ссылаться обратно** на хаб за философией и
  межпроектным контекстом.
- Когда проект достаточно велик, чтобы вести собственную документацию, хаб
  сокращает своё освещение до записи на карте плюс ссылок.

## Как строятся сайты

Каждый сайт документации (включая этот) собирается с помощью
[lagrange](https://github.com/celestia-island/lagrange) из Markdown в
репозитории проекта, с общим переключателем языков. Контент пишется на
английском; переводы следуют той же структуре и помечаются, когда неполны.
