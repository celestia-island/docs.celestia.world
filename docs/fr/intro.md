# Bienvenue sur celestia-island

**celestia-island** est une suite de projets pour le contrôle industriel par IA :
collaboration multi-agents, opérations à distance et automatisation critique pour
la sécurité. Ce site en est le *pourquoi*. Le *comment* vit dans la
documentation de chaque projet.

## Les projets

Un nom accompagné d'un lien est un dépôt public que vous pouvez lire dès
aujourd'hui. Un nom sans lien est un produit livré avec la plateforme dont les
sources ne sont pas encore publiques. Le tableau détaillé se trouve dans la
[Carte des projets](./ecosystem/projects.md).

**Plateforme** — [kirino](https://github.com/celestia-island/kirino)
(authentification zero-trust), [plana](https://github.com/celestia-island/plana)
(protocole et infrastructures de plateforme),
[hikari](https://github.com/celestia-island/hikari) (composants UI),
[provider-registry](https://github.com/celestia-island/provider-registry)
(catalogue de modèles), arona (panneau de déploiement de modèles), entelecheia
(orchestration d'agents), shittim-chest (chat et atelier), scriptum (client
terminal).

**Industriel et périphérie** — evernight (courtier de protocoles),
[aoba](https://github.com/celestia-island/aoba) (CLI Modbus),
[hare](https://github.com/celestia-island/hare) (pont `no_std`),
[kei](https://github.com/celestia-island/kei) (noyau de périphérie),
[shun](https://github.com/celestia-island/shun) (installateurs et programmeurs de
flash), electrode_recon (moteur de calcul).

**Bibliothèques et outils** — [noa](https://github.com/celestia-island/noa)
(contrôle de version natif agents), [seia](https://github.com/celestia-island/seia)
(recherche web), [aris](https://github.com/celestia-island/aris) (moteur de
navigateur), [shirabe](https://github.com/celestia-island/shirabe)
(automatisation de navigateur), [kou](https://github.com/celestia-island/kou)

(pipelines de threads), [yuuka](https://github.com/celestia-island/yuuka) (macros

versionnée), [lacrymira](https://github.com/celestia-island/lacrymira) (accès typé
aux données), [himari](https://github.com/celestia-island/himari) (RI de

[ayane](https://github.com/celestia-island/ayane) (service de messagerie),

**Infrastructure** — [celestia-devtools](https://github.com/celestia-island/celestia-devtools)
