# Краткое руководство

Пройдите [замкнутый цикл](../philosophy/closed-loop.md) примерно за 30 минут.
Точные адреса зависят от вашего развёртывания; спросите у администратора URL
панели и ваше приглашение.

## 1. Получите учётную запись

Регистрация закрыта приглашениями: первый пользователь развёртывания
становится администратором, после чего самостоятельная регистрация
блокируется. Свяжитесь с мейнтейнерами за приглашением, затем
зарегистрируйтесь через панель (`https://dev.celestia.world` в публичном
развёртывании или URL панели вашего администратора).

## 2. Создайте API key

В панели создайте API key для своей учётной записи. Этот ключ — ваша
личность для всего ниже: управление моделями, чат-бэкенды и операции агентов.

## 3. Разверните модель

В панели выберите рантайм модели, разверните её на узле и привяжите к
чат-бэкенду. Панель показывает здоровье и использование; учёт и тарификация
обрабатываются платформенным слоем. Что делает каждый шаг — см.
[Arona](../platforms/arona.md).

## 4. Общайтесь и запускайте агентов

Откройте [shittim-chest](https://dev.celestia.world) (desktop-приложение или
webUI), подключитесь с вашим API key и начните диалог. Для мультиагентной
работы агентная платформа оркестрирует за тем же интерфейсом; журналы агентов
и вызовы инструментов видны в UI. См. [Shittim Chest](../platforms/chest.md) и
[Entelecheia](../platforms/entelecheia.md).

## 5. Управляйте промышленным оборудованием

С запущенным [evernight](../platforms/evernight.md) подключите протокольный
мост (Modbus, S7comm, OPC UA), подпишитесь на телеметрию и — после проверки
политик и подтверждения человеком — выполняйте записи. Во время внутренней
беты этот сегмент работает с симуляционным или лабораторным оборудованием;
цепочка безопасности в обоих случаях идентична.

## 6. Проверка

Проверьте статус наблюдения (сервисы под управлением
[malkuth](https://github.com/celestia-island/malkuth)), просмотрите записи
использования и сообщайте о проблемах через каналы из
[бета-руководства](./beta-guide.md). Если что-то сломано, цикл не завершён —
расскажите нам, где.

## Что делать, если что-то не работает?

- **Сервис лежит** — наблюдение должно было перезапустить его; проверьте
  страницу статуса сервисов или журналы.
- **Панель не открывается** — убедитесь, что вы на правильном хосте/порту.
- **Память или извлечение недоступны** — ответ API и UI помечают это явно;
  чат всё равно работает и без этого.
