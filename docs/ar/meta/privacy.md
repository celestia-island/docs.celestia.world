# سياسة الخصوصية

توضح هذه السياسة البيانات التي تجمعها خدمات celestia-island خلال النسخة التجريبية المغلقة وكيفية استخدامها.

## ما نجمعه

- **بيانات الحساب** — عنوان البريد الإلكتروني وبيانات الحساب الوصفية اللازمة لتشغيل حسابك.
- **سجلات الاستخدام** — بيانات استخدام الـ API والخدمات، وتُستخدم للقياس والفوترة خلال الفترة التجريبية وبعدها.
- **السجلات** — سجلات الطلبات والخدمات الناتجة عن التشغيل الطبيعي.

## كيف نستخدمها

- **تشغيل الخدمة** — تشغيل الخدمات والمصادقة والدعم.
- **منع إساءة الاستخدام** — اكتشاف إساءة الاستخدام أو الهجمات والاستجابة لها.
- **قياس الاستخدام** — قياس الاستخدام لأغراض الفوترة الداخلية وتخطيط السعة.

## الاحتفاظ

تُحفظ البيانات للمدة اللازمة للأغراض أعلاه فقط. تُحفظ السجلات عادةً لمدة 30 يومًا؛ وتُحفظ بيانات الحساب والاستخدام طوال عمر الحساب زائد أي مدة يقتضيها القانون المعمول به.

## ما لا نقوم به

- نحن لا **نبيع** بياناتك.
- لا نجمع أو نعالج بيانات بطاقات الدفع؛ وأي معالجة للمدفوعات مستقبلًا ستتولاها جهات خارجية وفق سياساتها الخاصة.

## التواصل

الأسئلة حول هذه السياسة: افتح issue في مستودع [celestia-island](https://github.com/celestia-island) المعني.
