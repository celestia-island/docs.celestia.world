# Willkommen bei celestia-island

**celestia-island** ist eine Suite von Projekten für industrielle
KI-Steuerung: Multi-Agenten-Kollaboration, Fernoperation und
sicherheitskritische Automatisierung. Diese Seite ist ihr *Warum*. Das *Wie*
lebt in den projekteigenen Dokumentationsseiten.

## Die Projekte

Ein Name mit Link steht für ein öffentliches Repository, das Sie heute lesen
können. Ein Name ohne Link steht für ein Produkt, das mit der Plattform
ausgeliefert wird und dessen Quelle noch nicht öffentlich ist. Die
ausführliche Tabelle steht in der
[Projektübersicht](./ecosystem/projects.md).

**Plattform** — [kirino](https://github.com/celestia-island/kirino)
(Zero-Trust-Auth), [plana](https://github.com/celestia-island/plana) (Protokoll
und Plattform-Grundlagen), [hikari](https://github.com/celestia-island/hikari)
(UI-Komponenten),
[provider-registry](https://github.com/celestia-island/provider-registry)
(Modellkatalog), arona (Panel für Modellbereitstellung), entelecheia
(Agenten-Orchestrierung), shittim-chest (Chat und Werkbank), scriptum
(Terminal-Client).

**Industrie und Edge** — evernight (Protokoll-Broker),
[aoba](https://github.com/celestia-island/aoba) (Modbus-CLI),
[hare](https://github.com/celestia-island/hare) (`no_std`-Bridge),
[kei](https://github.com/celestia-island/kei) (Edge-Kernel),
[shun](https://github.com/celestia-island/shun) (Installer und Flasher),
evernight-appliance (die Appliance-Distribution), electrode_recon (Rechen-Engine).

**Bibliotheken und Werkzeuge** — [noa](https://github.com/celestia-island/noa)
(agentennative Versionskontrolle), [seia](https://github.com/celestia-island/seia)
(Websuche), [aris](https://github.com/celestia-island/aris) (Browser-Engine),
[shirabe](https://github.com/celestia-island/shirabe)
(Browser-Automatisierung), [kou](https://github.com/celestia-island/kou)
(virtuelles Terminal), [ichika](https://github.com/celestia-island/ichika)
(Thread-Pipelines), [yuuka](https://github.com/celestia-island/yuuka)
(Struktur-Makros), [hifumi](https://github.com/celestia-island/hifumi)
(versionierte Serialisierung), [lacrymira](https://github.com/celestia-island/lacrymira)
(typisierter Datenzugriff), [himari](https://github.com/celestia-island/himari)
(Formel-IR), [kotama](https://github.com/celestia-island/kotama)
(Reverse-Engineering), [ayane](https://github.com/celestia-island/ayane)
(Mail-Dienst), [tairitsu](https://github.com/celestia-island/tairitsu)
(Full-Stack auf dem Component Model),
[akivili](https://github.com/celestia-island/akivili) (Plugin-Host),
[celestia-plugin](https://github.com/celestia-island/celestia-plugin)
(Python-SDK), [ratatui-markdown](https://github.com/celestia-island/ratatui-markdown)
(Markdown im Terminal), arcaea (Persona-Protokoll), official-plugins
(Plugin-Pakete).

**Infrastruktur** — [celestia-devtools](https://github.com/celestia-island/celestia-devtools)
(Build- und Lint-Toolchain),
[cherino](https://github.com/celestia-island/cherino) (Agenten-Container),
[malkuth](https://github.com/celestia-island/malkuth) (Service-Überwachung),
[lagrange](https://github.com/celestia-island/lagrange) (die Dokumentations-Engine
hinter dieser Seite),
[celestia-artifacts](https://github.com/celestia-island/celestia-artifacts)
(Release-Artefakte), [sysl](https://github.com/celestia-island/sysl) (die
Lizenz), celestia-integration (Integrationstests), fuuka (selbst gehostete
CI), celestia-erp (kaufmännisches Backoffice).

**Sites** — [celestia-island.github.io](https://celestia-island.github.io),
[e.celestia.world](https://e.celestia.world),
[dev.celestia.world](https://dev.celestia.world) (das Panel, während der Beta
