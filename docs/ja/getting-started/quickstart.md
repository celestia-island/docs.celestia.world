# クイックスタート

[クローズドループ](../philosophy/closed-loop.md) を約 30 分で歩きます。
正確なアドレスはデプロイメントによって異なります。パネル URL と招待状
は管理者に確認してください。

## 1. アカウントを取得する

登録は招待制です。デプロイメントの最初のユーザーが管理者になり、その
後は自己登録がロックされます。メンテナーに招待状を依頼してから、
パネルで登録します（公開デプロイメントでは
`https://dev.celestia.world`、または管理者から渡されたパネル URL）。

## 2. API キーを作成する

パネルで自分のアカウントの API キーを作成します。このキーは
以下すべての身分となります —— モデル管理、チャットバックエンド、
エージェント操作。

## 3. モデルをデプロイする

パネルからモデルランタイムを選び、ノードにデプロイし、チャットバック
エンドにバインドします。パネルにはヘルスと利用状況が表示されます。
計測と価格設定はプラットフォームレイヤが処理します。各ステップが何を
するかは [Arona](../platforms/arona.md) を参照してください。

## 4. チャットとエージェント実行

[shittim-chest](https://dev.celestia.world)（デスクトップ
アプリまたは WebUI）を開き、API キーで接続して会話を始めます。マルチ
エージェント作業では、エージェントプラットフォームが同じインターフェース
の背後でエージェントをオーケストレーションします。エージェントログと
ツール呼び出しは UI に表示されます。[Shittim Chest](../platforms/chest.md)
と [Entelecheia](../platforms/entelecheia.md) を参照してください。

## 5. 産業機器の制御

[evernight](../platforms/evernight.md) を起動しておき、プロトコル
ブリッジ（Modbus、S7comm、OPC UA）を接続し、テレメトリを購読して、
ポリシー検証と人間の確認の後に書き込みを実行します。内部ベータの間、
この区間はシミュレートされた機器またはラボ機器に対して実行されます。
安全チェーンはどちらの場合も同じです。

## 6. 検証

監視ステータス（[malkuth](https://github.com/celestia-island/malkuth)
が管理するサービス）を確認し、利用記録を調べ、問題があれば
[ベータガイド](./beta-guide.md) のチャネルで報告します。
何かが壊れていれば、ループは完成していません —— どこかを教えてください。

## 失敗したら？

- **サービスがダウンしている** —— 監視によって再起動されているはずです。
  サービスのステータスページまたはログを確認してください。
- **パネルが開かない** —— 正しいホスト/ポートで開いていることを確認してください。
- **メモリまたは呼び出しが利用できない** —— API レスポンスと UI が
  明示します。チャットはそれがなくても動作します。
