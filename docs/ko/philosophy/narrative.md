# 내러티브와 지평

## 지연은 운명입니다

신호 왕복은 달까지 **2.6초**, 화성까지 **6분에서 44분**이 걸립니다. 지구에서
그렇게 멀리 떨어진 기계는 인간의 지시를 기다릴 수 없습니다. **로컬에서,
안전하게, 예측 가능하게** 결정을 내려야 합니다 — 행동할 권한과 거부할
규율을 모두 갖추고 말입니다.

이것이 이 생태계가 지향하는 지평입니다. 우리가 오늘 산업 제어를 위해
구축하는 모든 것은 자율적인 달 또는 화성 로봇이 필요로 할 것과 *같은 형태*
가 되도록 선택됩니다:

- 계획을 세우고 오케스트레이션하는 **에이전트 의사결정 계층**
- 지금 무슨 일이 일어나고 있는지 아는 **세계 모델**
- 네트워크에 절대 의존하지 않는 실시간 제어로 뒷받침되는, 아니요라고 말할
  수 있는 **안전 게이트**

달은 마케팅 스토리가 아닙니다: 그것은 계층화가 존재하는 이유입니다.

## 로드맵

생태계는 게이트를 통해 전진합니다 — 이전 단계가 종료 기준을 충족할 때만
다음 단계가 열립니다:

| 단계 | 목표 시점 | 종료 기준 |
| --- | --- | --- |
| **내부 베타** | 지금 | P0 보안 이슈 0건; 전체 루프가 통합 테스트 통과; 새 사용자가 30분 안에 등록 → API key → 채팅 진행 |
| **공개 베타** | 2026 | 공개 등록; 공개 문서, 다운로드, 법적 페이지; 독립 보안 검토 |
| **Y1 — 산업 라인** | 2027-08 | 실제 PLC + MCU 생산 라인 데모: 100 Hz 센싱, 10 Hz 폐쇄 루프, 배포 패키지, 승인 테스트 |
| **Y3 — 구현 시설** | 2029-08 | 재현 가능한 구현 시설 패키지(세계 상태 + 정책 계층 + 참조 사이트), *산업 구현* 형태로 고정 |
| **Y5 — 항공우주** | 2031-08 | 완전한 소프트웨어/하드웨어 제안과 궤도 또는 비행 증명 최소 1건 — 실적 없음, 판매 없음 |
| **Y5+ — 달/화성** | 2031+ | 자율성 내러티브, 연구 파트너십, 백서 |

## 네 개의 트랙이 하나의 자산 기반을 공유합니다

1. **트랙 B — 산업 제어** ([evernight](https://github.com/celestia-island/evernight)
   메인 스테이지): 센서 파이프라인, 기록/재생, 고속 루프, 임베디드 노드.
2. **트랙 E — 구현 지능**: 세계 상태 서비스, 소형 로컬 모델을 가진 정책
   계층, 디지털 트윈 시각화.
3. **트랙 K — kei 실시간 코어**: Linux ABI 퍼스낼리티 계층을 가진 결정적
   커널 — 유계적이고 예측 가능한 실행을 위한 장기적 답.
4. **트랙 S — 항공우주**: 시스템 수준 삼중 모듈 중복, 비행 실적, 인증 트랙.

모든 트랙을 하나로 묶는 규율이 있습니다: **와이어 프로토콜, 세계 상태, 안전
게이트, 기록 파이프라인은 공유 자산입니다.** 새 자산을 시작하는 트랙은
아키텍처 리뷰를 통과해야 합니다. 그리고 제품 라인은 절대 kei에 의존하지
않습니다: kei가 지연되어도 수익은 지연되지 않습니다.
