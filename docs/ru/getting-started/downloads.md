# Загрузки

Что вы устанавливаете, зависит от вашего места в замкнутом цикле. Во время
внутренней беты большинству участников нужно только desktop-приложение; всё
остальное размещает ваш администратор или оно необязательно.

## Desktop-приложение (shittim-chest)

Desktop-приложение shittim-chest публикуется с каждого тега `v*`. Установщики
**неподписаны** — ожидайте предупреждение безопасности ОС при первом запуске.
Страница загрузки остаётся пустой, пока не выдвинут первый бета-тег.

| Платформа | Артефакт |
| --- | --- |
| Linux | `.AppImage` или `.deb` |
| Windows 10+ | `.exe` (NSIS) или `.msi` |
| macOS | пока не публикуется |

Релизные сборки покрывают только Linux и Windows; macOS не входит в
релизный конвейер. До первого релиза (или если вы предпочитаете обойтись без
установки) используйте [webUI](https://dev.celestia.world) shittim-chest.

## Админ-панель (arona)

Arona размещается на сервере — локально устанавливать нечего. Откройте URL
панели, который даёт ваш администратор, и войдите со своим приглашением.

## Рантайм агентов (необязательно)

Пользователи, которые запускают агентную платформу сами, используют
унифицированный установщик в
[plana](https://github.com/celestia-island/plana/tree/master/scripts/install)
([Linux/macOS](https://github.com/celestia-island/plana/blob/master/scripts/install/celestia-install.sh),
[Windows](https://github.com/celestia-island/plana/blob/master/scripts/install/celestia-install.ps1)).
Всё собирается из собственных репозиториев экосистемы, поэтому необходимые
условия — тулчейн Rust, Docker и средство запуска задач `just`.
