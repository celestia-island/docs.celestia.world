# 快速开始

约 30 分钟走完[闭环](../philosophy/closed-loop.md)。具体地址取决于你的部署；面板地址与邀请请咨询管理员。

## 1. 获取账户

注册是邀请制：部署首个用户自动成为管理员，此后自助注册上锁。向维护者索取邀请，然后在 Arona 面板注册（公网部署 `https://arona.celestia.world`，内网 `http://<主机>:8420`）。

## 2. 创建 API 密钥

在 Arona 面板为账户创建 API 密钥。这个密钥是你下面一切操作的通行证——模型管理、聊天后端与智能体操作。

## 3. 部署模型

在面板中选择模型运行时（例如 Ollama 后端模型），部署到节点，绑定聊天后端。面板展示健康与用量；计量与定价由平台层处理。

## 4. 聊天与智能体

打开 [shittim-chest](https://shittim-chest.docs.celestia.world)（桌面应用或 WebUI），用 API 密钥连接并开始对话。多智能体场景下，entelecheia 的 scepter 运行时在相同界面背后编排智能体；智能体日志与工具调用在 UI 中可见。

## 5. 控制工业设备

[evernight](https://evernight.docs.celestia.world) 运行后，接入协议桥（Modbus、S7comm、OPC UA），订阅遥测，并在策略校验与人工确认后发起写操作。内测期间此环节运行于模拟或实验室设备；安全链在两种情况下完全相同。

## 6. 验证

查看监督状态（malkuth 管理的服务）、检查用量记录，并按[内测指南](./beta-guide.md)的渠道上报问题。若有断裂，说明闭环尚未完成——告诉我们断在哪里。

## 出了故障怎么办？

- **服务挂了** —— malkuth 应已重启它；查看服务状态页或日志。
- **面板打不开** —— 确认主机/端口正确，且部署时启用了内嵌 webUI。
- **记忆或召回不可用** —— API 响应与 UI 会显式标注（`memory: "offline"`）；聊天仍可工作。
